# Baustellen-App

## Mail-Test (Android)

Kleine Test-App: prüft, ob eine fertige Mail mit Empfänger, Betreff, Text und Anhängen (Foto + PDF) an eM Client übergeben werden kann.

**Installieren:** Unter „Releases“ → „Mail-Test (neueste Version)“ die Datei `MailTest.apk` auf dem Handy herunterladen und öffnen. Android fragt einmal, ob Apps aus dieser Quelle installiert werden dürfen.

Die APK wird bei jeder Änderung automatisch von GitHub Actions gebaut.
